# Proyecto: Entrenador Personal IA

## Objetivo

Desarrollar un entrenador personal IA capaz de actuar como coach de entrenamiento y nutrición de forma personalizada.

El sistema debe:

- Mantener memoria persistente del usuario.
- Analizar progresión y rendimiento.
- Detectar fatiga, estancamiento y tendencias.
- Utilizar evidencia científica mediante RAG.
- Adaptar recomendaciones automáticamente.
- Funcionar como un asistente conversacional continuo.

## Visión final

Crear un sistema que combine:

- Motor determinista de entrenamiento.
- Memoria de usuario.
- Base de conocimiento científica.
- LLM para razonamiento y comunicación.
- Nutrición personalizada.
- Insights automáticos.

El objetivo no es crear únicamente un chatbot, sino un sistema inteligente capaz de tomar decisiones fundamentadas utilizando datos del usuario y conocimiento científico.
